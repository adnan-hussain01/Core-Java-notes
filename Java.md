WHAT IS PROGRAMMING LANGUAGE?
-----------------------------
A Programming Language is a medium of communication between a programmer and a computer.
It allows programmers to write instructions that a computer can understand and execcute.
EX:C,C++,Java,Python.

Characteristics of Java Programming Language:
---------------------------------------------
Java Language has provided two characteristics:

1) Syntax (Rules given by java programming language)
2) Semantics (Structure OR Meaning given by java programming language)

 Syntax:
 ------
 Every Programming language has provided some syntax so, developer should allow while writing the code.

 Ex:
 ----
 Subject + Verb + Object (English Grammar Rule)
 He is a boy. / valid
 He is a box. //Invalid

 In the syntax part our compiler will only verify the syntax of the code, It will never verify whether the code is meaningful or meaningless.
 Ex:
 ---
 int x = 10;
 int y = 0;
 int z = x/y;

 Note: The above code will compile without any problem but at runtime our runtime environment will generate runtime error.
 
 Semantics:
 ----------
 In Semantics, Our runtime environment will verify whether the code is meaningful or not, It will verify the structure, If everything is correct then only it will execute the code.

 So the final conclusion is, Our Java Code will be verified by two times:

 a) At the time of compilation [Syntax Verification]
 b) At the time of execution [Semantics Verification]
